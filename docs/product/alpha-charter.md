# Freehold Alpha Charter

## Why this exists

Freehold is building an internet without landlords. Its first product is for independent writers: a place to own an archive, publish on a personal site, and syndicate outward. Writing is the first doorway, not the final boundary.

This Alpha is the first Freehold host and reference app. It is not a temporary writer product that will later be transformed into something participants did not agree to join.

## User compact

Freehold commits that:

1. A creator's canonical work belongs to that creator.
2. Canonical content is published at stable Freehold URLs and is exportable in a documented, versioned format.
3. Freehold will not inject advertising into creator work or sell creator data.
4. A new discovery, federation, or social feature does not broaden existing content visibility without affirmative user action.
5. Users will receive advance notice of material changes to these commitments and retain a practical path to export their data.
6. The product will distinguish shipped functionality from planned architecture. It will not claim host portability until a successful cross-install export/import migration proves it.

## Alpha scope

### Included

- Managed identity for a single local writer
- Public Notes and Articles in the local writer interface
- Canonical path generation for each post
- Versioned local archive export
- Synthetic demo content only

### Explicitly deferred

- Remote authentication and account recovery
- External object storage and production backups
- Custom domains and DNS migration
- Connected Bluesky/Mastodon accounts and POSSE
- Private or paid feeds
- Reader accounts, follows, replies, comments, and discovery
- ActivityPub, AT Protocol, moderation lists, and multi-host migration

## Exit criteria for the next phase

Before inviting real writers, Freehold must add authenticated accounts, durable encrypted backups, import/export round-trip coverage, consented syndication, and a documented privacy/security review.
